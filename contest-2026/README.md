## 七、环境备忘（踩过的坑）

1. **大数组一律开全局。** 局部变量在栈上，Windows 默认 1MB；`stu S[100005]` 约 4MB，一进 main 就崩，现象是"程序没法输入"。
2. `endl` 每次 flush，循环里用 `"\n"`。
3. 用 `printf` 要 `#include <cstdio>`。
4. 提交前固定三行：`输入：… 实际：… 期望：…`。
