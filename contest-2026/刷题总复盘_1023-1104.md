## 二、逐题详情：我卡在哪

### 1. 验证题 A（和 / 最大值 / 平均值）
**坑：**
- 把「n 个数」硬编码成 3 个数（`cin >> x >> y >> z`）——没意识到 n 是变量
- `int sum` 存 1e11 → 溢出
- `sum / num` 整数除法截断，没加 `(double)`
- `mx` 定义在循环里 → 出了循环就不存在（作用域）
- `mx` 每轮重置成当前值 → 求出的最大值永远是最后一个数
- 漏 `cin >> n`、漏输出 `mx`

**教训：** 数据范围决定类型；跨轮保存的变量必须定义在循环外，只更新不覆盖。

### 2. 区间排序
**坑：** 第一次见 `vector` 和 `pair`，不知道 `push_back` 只能塞一个元素；不确定 `pair` 的默认比较规则。

**教训：** `pair` 默认比较 = 先 `first` 后 `second`，都是升序。题目要求与之一致时，**不用写 cmp**。

### 3. P1093 奖学金
**坑：**
- 把 `cmp` 写进 `struct` 里（cmp 是独立函数）
- `bool cmp(struct )` 签名写不出
- 同分比较方向反了（该 `<` 写成 `>`）
- `stu S[20]` 装不下 1e5
- 读入顺序按记忆写成「分数 姓名」（题面是「姓名 分数」）
- 4MB 数组开在 main 里 → 栈溢出，现象是"程序没法输入"
- 只输出前 5，没处理 n < 5 的越界

**教训：** `cmp` 多层用独立 `if` 返回，不要 `else if` 套娃；大数组一律开全局。

### 4. 2025#2 动物观测区域划分
**坑：**
- `gap` 写成「最后一个点 − 第 i 个点」，不是相邻间隔
- 切 k 段写成切 k 刀（应为 k−1）
- 过滤条件写 `<= 2000`（题面是 ≥2000 剔除，应 `< 2000`）
- 没判 `剔除后点数 < k`
- 坐标用 `int` 读（题面说长整数）

**教训：** 区间分割类题：总长 = 首尾跨度 − 被切掉的间隔；要最大就切最小的。官方答案也会和题面不一致，**以题面为准**。

### 5. 2024#2 修复公路
**坑：** 漏了 `+ m`——段长度定义为「末 − 首 + 1」（包含的整数点数），不是坐标差。答案差一个常数，样例能过、隐藏点全挂。

**教训：** 样例说明里给了每段长度时，**必须反推出长度定义**，不要假设。

### 6. 2025#1 加密解密
**坑：**
- 想用二维 `vector` 先分组存起来（在 Python 里自然，在 C++ 里浪费且踩作用域）
- `vector<int> v` 定义在 j 循环里 → 每轮销毁，`push` 进去全是空
- 内层循环起点写成 `0`，第一组对、后面全错

**教训：** 原地操作 = 存首 → 后面整体前挪 → 首放尾。

### 7. 二叉树三种遍历（课内）
**坑：** 以为递归里 `u` 不变，问「u 又不会变，怎么遍历下面的子树」。实际每次调用参数是新的局部变量。

**教训：** 递归参数是每次调用的局部副本；要跨轮保存的东西才定义在外面。

### 8. 层序 + 深度 + 叶子
**坑：**
- 队列里放什么想不出（猜 `root++`）
- 不知道 `q.pop()` 不返回值，必须先 `front()` 存
- 空结点深度返回 0 还是 1 搞混

**教训：** BFS 为什么按层——同层结点入队时排在下一层前面，所以不跳层。

### 9. 先序 + 中序建树
**坑：**
- 4 个区间端点完全想不出
- `len` 写成 `k - pl`（应为 `k - il`）
- 不理解「结构体数组池」是什么

**教训：** 先序第一个是根；中序里根的左边是左子树；`len = k - il`。自检公式：`pr − pl == ir − il`。

### 10. 2019#47 左子树最大值
**坑：**
- `findmax(T)` 里递归调用传自己 → 死递归
- 调用时传 `p` 而不是 `p->left`
- `find` 应该返回指针（后面要用 `p->left`），一开始想返回 bool

**教训：** 求「某结点的子树」时，函数参数要传那个子树，不是整棵树。

### 11. 2019#48 右子树求和
**坑：**
- `if (!p) return p;` 条件反了——左子树找到反而不返回
- main 里三个分支写成并列 `if`：`p == NULL` 时去读 `p->rchild` → 空指针崩溃
- `sum` 在分支外输出，前两个分支会打出垃圾值

**教训：** 互斥分支必须 `if / else if / else`；每个分支自己输出。

### 12. 2019#49 判断子孙
**坑：**
- `stringstream ss1(line1)` 用了第一行，且写进 `pre[]` → `in[]` 全 0，建树找不到根
- `new` 被注释掉，但 `p->lchild = ...` 还留着 → 野指针写入，直接崩

**教训：** 注释掉创建时，顺手删掉所有依赖它的行。`new` 出来的对象要初始化成员，没指向对象的指针连 `->` 都不能用。

### 13. 区间选点
**坑：** 贪心策略想不出（虽然「放在区间最后」是常识）；`while` 扫描循环写不出——不知道比的是「后续区间」而不是「当前区间」。

**教训：** 取当前区间右端点为点，跳过所有「左端点 ≤ 该点」的区间。

### 14. LeetCode 875
**坑：** `check` 返回类型写成 `int`，但 `sum` 是 `long long`。用例 `3 × 805306368 = 2,415,919,104` 超 int，溢出成负数 → 被判定"可行"。

**教训：** **数据范围不只决定变量类型，也决定函数返回值类型。**
