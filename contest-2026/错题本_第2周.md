## 一、本周错题

| 2025#1 加密解密 | 内层循环起点写成 `0`，从第二组开始把前面的数据搅了 | 原地循环移位：存首 → 后面整体前挪 → 首放尾；起点必须是 `start` | `for (int j = start; j < start + k - 1; j++) a[j] = a[j+1];` | 11-02 |

| 2019#48 右子树求和 | `if (!p) return p;` 条件反了；三个分支写成并列 `if`，`sum` 在分支外输出 | 互斥分支必须 `else if`；每个分支自己输出 | `if (p) return p;` / `else if (p->rchild == NULL)` | 11-05 |
| 2019#49 判断子孙 | `ss1(line1)` 用了第一行；`new` 注释掉但保留了 `p->lchild` 赋值 → 野指针 | 读第二行要用 `line2`；指针变量不需要先 `new` | `stringstream ss1(line2);` / `BiTree p = find(T->lchild, num);` | 11-05 |
| 区间选点 | 扫描循环写不出（`while` 里比的是后续区间，不是当前） | 取当前区间右端点为点，跳过所有左端点 ≤ 该点的区间 | `while (i<n && a[i].l<=p) i++;` | 11-06 |
